# Online Quiz Application

## 📌 Project Overview

The Online Quiz Application is a console-based Java application that allows users to register, log in, and participate in quizzes.

The application provides a simple and interactive way to conduct quizzes through the command line.

## 🚀 Features

- User Registration
- User Login
- Quiz Participation
- Multiple-choice Questions
- Automatic Score Calculation
- Quiz Result Storage
- File-based Data Storage
- Simple Console-based Interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling
- Collections
- Git & GitHub
